# docker-rasenmaeher-integration 260921

**Release date:** 2026-10-11

## TL;DR

**TAK Server configuration now persists.** Admin changes to `CoreConfig.xml` that are not managed by ENV variables (federations, group mappings, custom listeners etc.) survive restarts and upgrades. Only explicitly deployment-owned settings are merged in at startup.

**Slimmer TAK images** on Temurin Java 17 JRE / Noble:

- TAK Server 3.01 GB -> 1.69 GB
- takrmapi 1.15 GB -> 521 MB

**TAK Server 5.8-84.**

**UI upgrades** (https://github.com/pvarki/react-rasenmaeher-ui-v2/pull/77, 78, 81, 83, 84, 85, 86):

- Simplified login and mTLS enrolment flow on Android, iOS, Windows, macOS and Linux.
- Invite codes can disable the info modals in the main UI for users enrolling with them. Useful when you walk your users through enrolment yourself.
- The feedback form is retired for now; it will come back improved.

**Upgrade notes:** Recreate all TAK service containers together with the new images; an old container still running the old startup script can overwrite the saved configuration. Keep the existing TAK volume, it holds the admin configuration and certificates. The previous `CoreConfig.xml` is kept as `CoreConfig.xml.pre-authority-backup`. See the [docker-atak-server README](https://github.com/pvarki/docker-atak-server#persistent-administrator-configuration).

No breaking changes.

---

## Release Goals

- Admins can configure TAK Server (federations etc.) and expect the changes to persist across reboots.
- Smaller images: faster pulls and less disk on deployments.
- Easier enrolment for end users on every major platform.
