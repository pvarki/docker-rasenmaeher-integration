# docker-rasenmaeher-integration 261011

**Release date:** 2026-10-11

## TL;DR

**Two TAK Server configuration fixes** in image `5.8.84-261011`:

- LDAP refresh now defaults to `6000` milliseconds (6 seconds), replacing `60`, after upstream changed the interval's unit from seconds to milliseconds. The interval can be overridden with `LDAP_UPDATE_INTERVAL` in the TAK configuration container.
- New configurations explicitly set `MissionStrictUidMissionMembership="false"` to restore the expected mission-membership behavior.

TAK Server remains on **5.8-84**. All other submodule pointers are unchanged from the documented `260921` release.

**Upgrade notes:** Recreate the TAK service containers with the updated image and keep the existing TAK volume. LDAP settings are merged into the saved configuration on configuration-service startup. The mission-membership setting is outside the deployment-managed attribute list, so existing installations must explicitly set `MissionStrictUidMissionMembership="false"` on the `<network>` element in their saved `CoreConfig.xml` if they want this behavior, then restart the TAK services. Custom LDAP intervals must be passed into the configuration container; the integration Compose files do not expose a host-variable override for this setting.

No breaking interface changes or database migrations.

## Release Goals

- Correct the LDAP refresh interval for TAK Server's millisecond-based setting.
- Restore the expected mission-membership default for new installations.

## Improvements & fixes

- [takserver] Change the default LDAP refresh interval from `60` to `6000` milliseconds, avoiding excessively frequent refreshes after the upstream unit change ([commit](https://github.com/pvarki/docker-atak-server/commit/186b43b62f80cb98b5068ffd2afabc152e945242)).
- [takserver] Explicitly set `MissionStrictUidMissionMembership="false"` in the configuration template ([commit](https://github.com/pvarki/docker-atak-server/commit/cfc91590d37bf541b0fb35c0cbede06127d34146)). Both fixes are included in [docker-atak-server #142](https://github.com/pvarki/docker-atak-server/pull/142).
- Update the production and local TAK image tags to `5.8.84-261011` and `5.8.84-261011-local`, respectively, and advance the TAK Server submodule pointer ([commit](https://github.com/pvarki/docker-rasenmaeher-integration/commit/e0966a3b6ae8b6e7e4e48224ac66d5f64e414734)).
