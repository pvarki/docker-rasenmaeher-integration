# docker-rasenmaeher-integration 261027

## Highlights

- **Matrix Authentication Service (MAS)** now handles Matrix accounts and authentication, providing the authentication needed by Element X and other modern clients. Includes [Matrix integration #22](https://github.com/pvarki/python-matrix-rmapi/pull/22), [Synapse #6](https://github.com/pvarki/docker-synapse-server/pull/6), and [MAS #1](https://github.com/pvarki/docker-mas-server/pull/1).
- **Matrix room version 12** is supported, fixing bot-assigned room names with newer Synapse defaults ([Matrix integration #44](https://github.com/pvarki/python-matrix-rmapi/pull/44)).
- **TAK:** updated default maps, including Kapsi WMS and terrain sources; restored ATAK app launch from the enrolment modal; added federation peer/CA validation, trusted CA and group configuration, outgoing connections, and audit logging.
- **Security:** updated dependencies and service images, including Python security pins and TAK integration UI fixes for vulnerable Vite and Undici versions. LDAPs port `1636` is no longer published on the host.
- **Deployment:** generated `.well-known/required_env.txt`, `required_subdomains.txt`, and `required_ports.txt` describe Compose requirements. API healthchecks avoid importing the application, and CI reports healthcheck failures and validates image tags.
